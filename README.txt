AI FAKE WEBSITE DETECTION — BEGINNER SETUP (WINDOWS)

1. Extract this ZIP file into a folder.
2. Install Python from https://www.python.org/downloads/ if you do not already have it.
   During setup, tick "Add Python to PATH".
3. Double-click START_APPLICATION.bat.
4. Wait for the browser to open. If it doesn't, visit http://127.0.0.1:5000
5. Type a website URL into the app page and click Scan URL.
6. Keep the black command window open while using the app. Close it to stop.

This is an educational URL-warning demo. It uses basic rules rather than a trained production AI model, does not visit submitted sites, and cannot guarantee a website is safe. Do not use its result as proof of legitimacy.
